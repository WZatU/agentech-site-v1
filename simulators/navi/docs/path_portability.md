# Path Portability

The release targets Windows, Linux and WSL2.

- Production runtime resources resolve with `pathlib.Path` from the installed
  module location.
- Default output is `Path.cwd() / "results" / <unique-run-id>`.
- `--output` and `--config-dir` are explicit portable overrides.
- No production source contains a user directory, drive-letter dependency,
  Codex output path, fixed temporary directory or hard-coded ffmpeg path.
- Temporary verification work uses Python `tempfile`.
- ZIP entries always use POSIX relative names and reject absolute or `..` paths.

The automated evidence is generated by:

```bash
python tools/path_portability_audit.py
```

Latest release-gate output:

`outputs/release_validation/path_audit.md`.

Linux/WSL viewer use still depends on a working display/OpenGL configuration;
headless simulation and tests do not require a viewer window.
