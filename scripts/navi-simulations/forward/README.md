# Navi walk-forward simulation

This folder stores the locally approved simulation source for Navi
`Agentech.forward()`.

- Sequence: stand for 0.75 seconds, walk forward for 5 seconds, then stop.
- Approval tuning: 1.25 Hz step frequency and 0.080 m forward step length.
- Control: Navi's 12 leg torque actuators only; no root-position assistance.
- Website asset:
  `public/assets/products/agentech-library/navi-simulations/forward/navi-walk-forward.mp4`

This local website change must not be pushed until the remaining Navi movement
simulations are reviewed and approved.
